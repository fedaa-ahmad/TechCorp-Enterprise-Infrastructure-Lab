# TechCorp Enterprise Infrastructure & Security Lab

## Project Overview

This project focuses on designing, implementing,
managing, and securing a complete enterprise IT
infrastructure.

The environment simulates a real-world company
network with centralized system administration,
network services, security controls, and monitoring.

## Infrastructure Environment

| Component | Technology |
|---|---|
| Hypervisor | VMware ESXi 6.5 U3 |
| Physical Server | HP Server |
| RAM | 32 GB |
| Storage | 256 GB SSD |
| Operating System | Windows Server 2016 |
| Network | MikroTik RouterOS |
| Linux | Ubuntu Server |

## Main Objectives

- Enterprise Network Design
- Network Administration
- Windows Server Administration
- Active Directory Management
- DNS and DHCP Services
- Linux Administration
- Network Security
- Infrastructure Security
- Backup and Disaster Recovery
- Infrastructure Monitoring

## Security Implementation

- Network Segmentation
- Firewall Configuration
- Access Control
- Least Privilege
- Server Hardening
- Secure Remote Access
- Centralized Monitoring

## Project Documentation

All configurations, practical labs,
network diagrams, troubleshooting procedures,
and security implementations will be documented
throughout this project.
